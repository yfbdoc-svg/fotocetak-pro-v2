# Checklist uji FotoCetak Pro v0.4.0

Setelah EXE berhasil diunduh dari GitHub Actions:

- [ ] Aplikasi terbuka dengan tiga panel dan judul FotoCetak Pro.
- [ ] Panel kiri tampil sebagai grid 3 kolom foto setelah mengimpor beberapa JPEG.
- [ ] Dropdown urutan Terbaru/Nama mengubah susunan thumbnail.
- [ ] Pratinjau A4 tampil lengkap tanpa bagian kertas terpotong pada Fit ke Layar.
- [ ] Zoom slider 60%–250% berfungsi; saat diperbesar, pengguna bisa drag untuk pan.
- [ ] Garis potong terlihat di luar keempat sudut setiap foto.
- [ ] Pas Foto: ukuran 3×4 cm, custom, dan jumlah per foto mengubah layout.
- [ ] Pas Foto: rotasi, mirror, zoom crop, fokus H/V, brightness, contrast, saturation mengubah preview.
- [ ] Pas Foto: warna ruang kosong hanya terlihat saat Fit dipilih.
- [ ] Beralih mode Polaroid menampilkan tujuh ukuran, menyembunyikan pilihan ukuran Pas Foto.
- [ ] Tab Bingkai, Teks & Tanggal, dan Edit Foto menampilkan kontrol yang sesuai.
- [ ] Efek bingkai, teks, tanggal, stiker, dan crop juga muncul dalam PDF hasil ekspor.
- [ ] Simpan lalu buka kembali proyek .fcp: pengaturan jumlah, ukuran, dan edit bertahan.
- [ ] PDF diuji pada printer dengan mode Actual Size / 100%; ukuran 3×4 cm diukur secara fisik.

Jika GitHub Actions gagal, kirim teks error dari langkah `Periksa masalah kode`, `Uji dasar aplikasi`, atau `Build aplikasi EXE versi Release`.
